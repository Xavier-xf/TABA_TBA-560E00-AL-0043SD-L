# 大厅机分支器烧录



1. 烧录软件 `楼层分支器\笙泉单片机烧录软件\Database Installer\IcpProgrammer.exe`
2. 分支器代码 `楼层分支器\楼层分支器 *D32`



打开烧录软件 

```R
载入文件->AP->分支器D32\KeilPrj\OBJ\kevin.hex
```

插入ISP代码

```r
插入ISP代码->用户自定义的ISP代码->分支器D32\KeilPrj\OBJ\b2000_bootloader.hex
```



IAP存储区域 `2.0K`

配置如下

![image-20220913153744092](https://gitee.com/gexiaol/picgo/raw/master/img/image-20220913153744092.png)





烧录器

![image-20220815204120835](https://gitee.com/gexiaol/picgo/raw/master/img/image-20220815204120835.png)

将烧录器连接电脑后，在点击烧录软件的[设置脱机模式]

将烧录器连接板子后按下烧录器上的按钮

提示灯一直闪烁至烧录结束
